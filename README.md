# THE ARCHITECT

Interactive 2D / 3D teaching deck for the Reflexion argument: nested realities, the 2022
cross-layer write, the Ladder Operator, and the Nature Ontology evidence block.

First given 24 August 2026 at Hillsborough Baptist Church. Now public, so it can be
walked in an X Space or a room with no network.

**Live deck:** open the preview, press **Enter the Substrate**, arrows to travel.
**Repo:** [Shaximus/Reflexion-Architect-Presentation](https://github.com/Shaximus/Reflexion-Architect-Presentation)

## How to steer

| Key | Action |
|---|---|
| `→` `←` or Space | Next / previous scene |
| `V` | Toggle 3D world / 2D diagram |
| `E` | Present (talk density) / Explore |
| Click a node | Select it — same ID in 2D and 3D |
| Deep Dive | Mechanism, structure, residual |
| Source | Original wording from the corpus |
| `?` | Full guide |

Act IV of the Laws now includes the Ladder Operator and six Nature Ontology scenes.
Every nature scene carries its registered collision (COL_001–005) on the slide face,
not buried in a footnote. The Collision Ledger is the deck auditing itself in public.

## Offline

The deck is built to render with no network in the room. Fonts are self-hosted.
3D labels use a local typeface; missing glyphs must not fetch a CDN.

```
RX_OFFLINE=1 npm run dev
```
